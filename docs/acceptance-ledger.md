# PhoneBridge 需求—验收账本

## 最终目标

Windows 电脑通过 USB/ADB 连接 Android 手机。分享者选择手机并生成临时链接，访问者无需安装客户端，在浏览器中只查看和控制该手机。

## 不可妥协项

1. 访问者不能查看或控制分享电脑桌面。
2. 两端电脑均不要求公网 IP。
3. 浏览器端不安装 frpc 或桌面客户端。
4. 不向公网暴露 ADB 5037/5555。
5. WebRTC P2P 优先，失败后 TURN 中继。
6. 会话可过期、撤销、断线恢复；默认单控制者。
7. 演示模式不能作为真实手机视频与控制的完成证据。

## 首版目标环境

- Windows 10/11 x64 分享端；
- Android 8–15，USB/ADB；
- 当前版 Chrome 与 Edge；
- 桌面浏览器优先，移动端响应式可用；
- 自建 HTTPS 信令与 TURN 服务。

## 性能预算

- 正常首次出画面：不超过 5 秒；
- 短暂断网恢复：目标不超过 8 秒；
- 默认 720p / 30 FPS / 2–4 Mbps；
- P2P 正常网络目标操作延迟不高于 200 ms；
- TURN 路径目标操作延迟不高于 350 ms。

## 明确非目标

- iOS；
- 远程电脑桌面；
- ADB Shell、文件管理、APK 安装；
- 云端录像；
- 绕过 Android 安全画面、DRM 或锁屏；
- 多人同时控制同一设备。

## Tango 行为对齐基线（公开资料）

只参考 Tango 的公开帮助文档与可观察到的产品行为，不复制或尝试获取其私有代码。资料：

- [Share Device by Link](https://help.tangoapp.dev/remote-access/share-link/)
- [Automatic Sharing](https://help.tangoapp.dev/remote-access/auto-share/)

| Tango 运行规则 | PhoneBridge 的对应规则 | 当前状态 |
|---|---|---|
| 每次点“开始”生成一条新的随机链接 | 会话令牌由安全随机数生成，停止后令牌立即失效 | 已实现 |
| 分享端退出/停止，远端浏览器立即断开 | “停止分享”会关闭 WebRTC 并拒绝后续访问；下一步增加分享端心跳，使关闭本地控制页同样撤销链接 | 部分实现 |
| 可用同一链接从多个远端浏览器观看 | 多观看者会话；默认只授予一人控制租约，避免误触 | 待实现 |
| WebRTC 点对点优先，复杂 NAT 时使用 TURN | 已有 WebRTC 信令和 ICE/TURN 配置入口；需要部署公网信令与 TURN 才能完成跨网验证 | 部分实现 |
| 浏览器只看到被分享设备 | 控制页只渲染手机画面，未提供电脑桌面、文件或 ADB Shell 能力 | 已实现 |
| 链接本身不等于永久授权 | 可选 6 位访问码、会话时长、随时撤销 | 已实现 |

当前真实设备验证的结论：浏览器与本机 WebRTC 数据通道已连通；手机画面在 HTTP 兼容通道可正常获取。WebRTC 回传画面尚在排障，不能当作已完成的视频链路。
