## PhoneBridge v2.2.0

本次版本加入 88FRP 绑定域名分享，并修复节点切换后 WebRTC 仍使用旧 UDP 地址的问题。

### 新增

- 「设置 → 公网分享地址」新增“使用 88FRP 绑定域名作为分享地址”。
- 自动读取 88FRP 域名绑定的 A 记录，节点 IP 变化时分享主机名保持不变。
- 设置页显示绑定域名、当前 A 记录、节点地址和解析状态。
- 未启用域名绑定、没有 A 记录或读取失败时回退到节点 IP，并显示原因。
- 重启后恢复上次成功的公网地址，不再在自动登录完成前短暂显示“仅本机可用”。

### 修复

- 每 30 秒重新发现 88FRP UDP 映射；节点切换后自动更新 WebRTC 公网地址。
- 修复旧 UDP 地址残留导致页面能打开、但低延迟视频连不上的问题。

### 快速模式说明

- 88FRP 创建隧道时把远程端口填 `0`，表示自动分配一个可用端口；分配结果会写回该隧道的固定远程端口。
- 普通 frpc 重连、软件重启或短暂断线不会重新分配端口。
- 切换订阅节点、删除重建隧道或服务端回收端口时可能重新分配，届时旧分享链接会失效，需要重新生成。
- 域名绑定解决节点 IP 变化，不解决远程端口变化；去除端口需要 HTTP/HTTPS 隧道或反向代理。

### 验证

- `go test ./... -count=1` 通过。
- `go vet ./...` 通过。
- 真实公网域名健康检查返回 v2.2.0。
- 真实 88FRP 同步显示域名绑定为 `ready`，WebRTC UDP 映射为当前节点且状态为 `fresh`。
- 覆盖安装后版本为 2.2.0，本机设置和现有分享会话保留。

### 安装

下载 `PhoneBridge-Setup-2.2.0-Windows-x64.exe`。覆盖安装会自动识别原安装位置、保留设置，并在安装完成后自动启动。
